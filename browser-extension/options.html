File Rush Integration Module

Capture

File types

Extensions that File Rush takes over, separated by spaces.

Exceptions

Sites or address prefixes that the browser should handle itself, one per line (for example example.com or https://intranet/).

Setup

File Rush registers the native messaging host for Chrome, Edge, Brave, Vivaldi, Chromium and Firefox when it starts. If the popup reports that the host was not found, open File Rush, go to Options, General and press "Register browser integration".
